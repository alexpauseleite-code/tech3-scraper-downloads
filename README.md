# Tech3 Scraper downloads

Offline Windows installers for the Tech3 local scraper pilot.

[Download the Windows app](https://github.com/alexpauseleite-code/tech3-scraper-downloads/releases/latest)

[Open the web workspace](https://zoom-phone-lab.vercel.app/#scraper)

Python and a separate signed-out Chromium browser are included. Windows 10/11
x64; per-user installation without administrator rights. The pilot installer is
unsigned. Your computer must stay awake to scrape; the web browser can close.

Pair the tray app from the web workspace, select a business type, explicit
city/country, approximate search width and lead count/All, then Start local scrape.
Results sync to your lab workspace and can be exported or added to its call list.
No personal Google login, Google API key or Google Drive setup is required.

This repository distributes installer artifacts only. Source code is stored
separately. Release checksums and dependency notices accompany each release.
